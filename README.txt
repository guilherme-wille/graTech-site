GRATECH — SITE DEMONSTRATIVO
================================

TECNOLOGIAS
- HTML5
- CSS3
- JavaScript (não Java)

COMO ABRIR
1. Extraia a pasta gratech_site.zip.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
   Recomendado: instalar a extensão Live Server no VS Code e clicar em "Go Live".

PÁGINAS
- index.html: página inicial
- servicos.html: projetos e serviços
- membros.html: equipe
- contato.html: formulário e perguntas frequentes

OBSERVAÇÕES IMPORTANTES
- O layout foi reconstruído a partir do PDF enviado, mantendo as quatro páginas e a identidade visual verde-escura, off-white e verde-limão.
- Imagens e fotos originais do Figma não foram exportadas separadamente no PDF. Por isso, alguns espaços visuais foram recriados com elementos gráficos e gradientes. Substitua-os pelos arquivos originais para uma correspondência visual ainda maior.
- O formulário está apenas no front-end: valida os campos no navegador, mas não envia dados. Para receber mensagens reais, será necessário integrar um backend ou serviço de formulários.
- Os textos e dados de contato seguem o material enviado. Revise-os antes de publicar.
